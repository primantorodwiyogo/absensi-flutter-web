# 🕒 Sistem Absensi Karyawan (Flutter + Web Admin + API)

Proyek ini adalah sistem absensi digital yang memisahkan fungsi antara karyawan (aplikasi mobile) dan administrator (web admin).

## 📱 Fitur Utama
### Untuk Karyawan (Mobile)
- Absen masuk/keluar dengan GPS & foto selfie
- Ajukan cuti/izin
- Lihat riwayat absensi & jadwal kerja
- Mode online/offline

### Untuk Admin (Web)
- Monitoring kehadiran real-time
- Manajemen data karyawan & shift
- Geofencing area kerja
- Laporan otomatis & integrasi payroll
